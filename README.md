# 🏎️ MyCarGame - 3D Highway Overtake Driving Game

A high-speed 3D highway car driving and traffic overtaking game developed in **Unity 6 (URP)**.

---

## 🎮 Game Features
- **Mercedes-AMG CLS Sports Sedan:** Detailed black metallic sports coupe model with custom rims, illuminated LED head/taillights, and responsive driving physics.
- **Infinite 4-Lane Highway:** Seamless, endlessly recycled expressway with overhead gantries, crash barriers, streetlights, and colorful autumn scenery.
- **Dynamic AI Traffic:** 20 traffic cars cruising in 4 lanes with intelligent distance maintenance and functional brake lights.
- **Overtake & Near-Miss System:** Overtake traffic vehicles at high speeds to earn cash rewards, combo multipliers (`x2`, `x3`, `x4`...), and high-speed driving bonuses.
- **Procedural Audio:** Real-time synthesized combustion engine sound with RPM and throttle pitch scaling, tire skids, and reward bell chimes.
- **Universal Input Controls:** Supports Keyboard, Gamepad, and On-screen Touch/Mouse pedals.

## 🕹️ Controls

| Action | Keyboard Key | Virtual On-Screen Button |
| :--- | :--- | :--- |
| **Accelerate (Gas)** | <kbd>W</kbd> or <kbd>↑</kbd> | `GAS (W)` |
| **Brake / Reverse** | <kbd>S</kbd> or <kbd>↓</kbd> | `BRAKE (S)` |
| **Steer Left** | <kbd>A</kbd> or <kbd>←</kbd> | `◀ (A)` |
| **Steer Right** | <kbd>D</kbd> or <kbd>→</kbd> | `▶ (D)` |
| **Handbrake / Drift** | <kbd>Space</kbd> | `DRIFT (Space)` |
| **Cycle Camera Mode** | <kbd>C</kbd> | `CAM (C)` |
| **Toggle Headlights** | <kbd>H</kbd> | `LIGHTS (H)` |
| **Pause Menu** | <kbd>Escape</kbd> | `PAUSE` |

## 🚀 How to Run the Project (For Friends / Collaborators)

1. **Clone the Repository:**
   ```bash
   git clone <YOUR-GITHUB-REPO-URL>
   ```
2. **Open in Unity Hub:**
   - Open **Unity Hub**.
   - Click **Add** -> **Add project from disk**.
   - Select the cloned folder `MyCarGame`.
   - Open with **Unity 6 (6000.x)** (Recommended: `6000.3.x` LTS).
3. **Play the Game:**
   - In the Project window, navigate to `Assets/Scenes/MainScene.unity` and double-click to open it.
   - Click the **Play (▶️)** button at the top of the Unity Editor!
